SMART MUNIM SHOWCASE WEBSITE

Files:
- index.html       Main website
- style.css        Design and responsive layout
- script.js        Mobile menu and APK download button settings
- privacy.html     Starter privacy notice (must be completed/reviewed)
- terms.html       Starter terms (must be completed/reviewed)

IMPORTANT BEFORE PUBLICATION
1. Open script.js.
2. Replace ADD_YOUR_GITHUB_RELEASES_APK_LINK_HERE with the exact direct APK asset URL from GitHub Releases.
   It should look like:
   https://github.com/USERNAME/REPOSITORY/releases/download/v1.0/app.apk
3. Add official contact details to the contact/privacy/terms copy.
4. Review the Privacy Policy and Terms so they accurately describe the real app and its data practices.
5. Replace the illustrative dashboard artwork with actual app screenshots if desired. The current artwork is clearly labelled as an illustration.
6. Confirm every feature shown on the site exists in the published app.

PUBLISHING
This folder can be uploaded to a GitHub repository and served using GitHub Pages.
The site is static and does not need a backend.

The APK link has intentionally not been guessed. A wrong download link would break the main purpose of the website.


IMPORTANT: The APK is included in this folder. Keep Smart-munims-debug-build-18.apk in the same folder as index.html, style.css, and script.js when uploading all website files to your PUBLIC website repository. The Download APK button uses this local APK file.
